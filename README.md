# BlueDayinji — ESP32 蓝牙热敏打印机

> **ESP32 便携蓝牙热敏打印机**（仿"喵喵机"类产品）：手机 App 通过蓝牙把内容发给打印机，384 点热敏打印头逐行加热 + 步进电机走纸，实现"手机点一下，纸上出内容"。电池供电，支持电量检测。

## 功能特点

- 📱 **蓝牙 SPP 透传**：手机搜索 "MaoPaperang" 直接连接，无需额外硬件
- 📦 **自定义帧协议**：起始/类型/序号/长度/数据/CRC32 校验/结束，支持分帧传输与压缩打印
- 🔥 **384 点热敏打印头**：SPI 驱动 + 6 段（STB1~6）分时加热，按点数分片削峰，电池友好
- ⚙️ **步进电机走纸**：8 拍细分驱动，"打一行、走一行"
- 🔋 电池电压检测（5 秒采样）+ 自动关机时间设置（省电）
- 🎛️ 加热浓度可调（打印深浅）、按键打印测试页
- 📄 完整项目总结笔记见仓库根目录 `项目总结笔记.md`（小白友好，总分总格式）

## 硬件组成

| 模块 | 说明 |
|------|------|
| 主控 | ESP32 DevKit（Arduino 框架，PlatformIO 构建） |
| 打印头 | 384 点热敏打印头（SPI：CLK15 / MOSI13 / LAT12 / VHEN17 / STB1~6） |
| 电机 | 4 线步进电机（AP22 / AM23 / BP19 / BM21） |
| 供电 | 锂电池 + ADC 电压检测（GPIO34） |
| 交互 | 按键（GPIO5，测试页）、LED（GPIO18） |

## 通信协议（简述）

```
帧格式：0x02 | 命令类型(1B) | 序号(1B) | 数据长度(2B) | 数据(NB) | CRC32(4B) | 0x03
```

- 命令类型：偶数 = 手机发问（GET/SET），奇数 = 打印机应答（SENT）
- 支持命令：打印、压缩打印、查版本/SN/电量/温度、设浓度、走纸、测试页等 30+ 种
- CRC32 校验防传输错误，密钥可被手机重置

## 项目结构

```
src/         main.cpp（协议解析状态机）+ bluetooth_protocol / tph / motor / led / print_test
include/     头文件 + 引脚定义（main.h）
platformio.ini   PlatformIO 工程配置（esp32dev）
```

## 快速开始

1. 安装 PlatformIO，打开本项目
2. `pio run -t upload` 烧录到 ESP32
3. 手机蓝牙连接 "MaoPaperang"，用配套 App 发送打印内容
